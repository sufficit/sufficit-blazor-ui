# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Desenvolvedores que usam Sufficit.Blazor.UI e precisam descobrir, experimentar e integrar seus componentes. Público inferido da finalidade da biblioteca e da vitrine aprovada.

## Product Purpose
Biblioteca de componentes Blazor independente de frameworks visuais externos. O catálogo demonstra os componentes reais e documenta integração, estados, composição e temas.

## Capabilities and Constraints
.NET 10; biblioteca Razor compartilhada; catálogo Server para validação e host WebAssembly para publicação estática via GitHub Pages. Dados dos exemplos são demonstrativos. API existente preservada. Idioma principal português brasileiro.

## Evidence on Hand
Código de src, documentação em docs/components, catálogo existente e suítes de componentes e navegador. A implementação foi autorizada após análise registrada em docs/ANALISE-CATALOGO-TEMAS-20260907.md.

## Product Principles
- Demonstrar o componente real junto do código utilizável.
- Manter a identidade configurável por tema.
- Preservar teclado, contraste e responsividade nos estados interativos.
- Reutilizar exemplos entre os modos Server e WebAssembly.
