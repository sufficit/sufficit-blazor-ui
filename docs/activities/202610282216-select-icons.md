# Ícones no SUISelect

Pedido: restaurar ícones da caixa postal usando API pública da biblioteca.

- SUISelect.StartIcon e IconColorValue: adorno fixo; SUISelectItem.Icon e IconColorValue: ícone da opção no menu e na seleção. Usa SUIIcon, tokens de cor e aria-hidden; não muda valores/nome acessível. Ausência de ícone não reserva espaço.
- Snapshot da opção inclui ícone/cor para atualização dinâmica. Estilos mantêm texto alinhado ao início, ícone sem compressão e uma única rolagem. Sem CSS na feature.
- Catálogo, exemplo, documentação e baseline pública atualizados (quatro parâmetros novos, nenhum removido).
- Restaurados ícones originais de saudação (success), despedida (warning), padrão (info) e silêncio no consumidor sufficit-blazor.
- 1135 testes da biblioteca passaram, incluindo dois testes novos de ícones/atualização dinâmica; primeira execução exigiu completar catálogo e baseline. Build consumidor/fixture: zero erros, avisos já presentes de dependências/código.
- npm run build:css e check:css passaram; 61556 B raw / 11229 gzip / 9791 brotli, dentro do orçamento.
- Playwright da fixture: 1440/768/390, ícones, seleção null/Guid.Empty/Guid, enum, Home/Enter/Escape, menu dentro do viewport, uma área rolável e sem pageerror. Captura móvel inspecionada; corrigido alinhamento após primeira inspeção. Evidências /tmp/voicemail-select-evidence.
- Limite: fixture com estado local; não valida backend/persistência nem página completa autenticada. Sem commit, release ou deploy. Deploy do consumidor segue pendente de decisão já solicitada por alterações alheias no checkout.
