# Ícone no fim do seletor

SUISelect oferece EndIcon, antes da seta, preservando StartIcon e os ícones das opções. IconColorValue colore os ícones fixos. Referência: captura do usuário; manter semântica e geometria SUI.

Caixa postal aplica EndIcon na saudação/despedida. Sidecar AI acompanha a disposição sem mudar contratos de dados.
