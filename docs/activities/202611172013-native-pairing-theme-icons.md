# Native pairing and appearance icons

SUIIcons now includes QR pairing, light theme and dark theme glyphs on the library's 24-pixel grid. The SVG paths are local and styled with the component's foreground color. The QR glyph is a visual label for pairing controls. Actual pairing codes still come from the provider.

The reviewed public API baseline includes the three new constants. The complete library test suite passed all 1,247 tests.
